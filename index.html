      About the model

      Planet positions use JPL's J2000 Keplerian elements (Standish, valid 1800 to 2050) propagated for the simulated date. Radii, rotation periods and axial tilts come from NASA's planetary fact sheets, spin-axis orientation from the IAU WGCCRE 2015 report. Solar day = 1 / (1/sidereal day − 1/year), with retrograde spin counted as negative. In visible scale sizes are enlarged and distances compressed so you can see everything; true scale shows the real, very empty, solar system. Eclipses and shadows are not modelled.

      Textures: Solar System Scope (CC BY 4.0), based on NASA imagery. Smaller moons and Pluto use procedural textures. Built with three.js. Source on GitHub.
